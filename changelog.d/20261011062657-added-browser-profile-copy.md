- **Browser profiles are copied aside before a new browser version first opens them.** A browser upgrades its profile on first open, and the older version may then refuse it. Before the browser tools open a profile with a different Camoufox or Chromium version, the profile is copied to `<profile>.pre-v<old version>-<time>` (caches left out), so going back to the old version can restore it. The newest copy per profile is kept, the newest of each version for 90 days, and older ones are removed after 14 days. A copy that cannot be made (low disk, profile open elsewhere) is logged and never blocks the launch.
