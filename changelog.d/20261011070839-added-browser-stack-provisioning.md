- **`scripts/install_browser_stack.sh` installs the browser stack in one step.** It fetches the Camoufox engine the installed camoufox package pairs with (camoufox 0.5.7 or later; never on an older package, whose fetch deletes the whole engine cache), installs patchright's Chromium when patchright is present, and installs missing system libraries through non-interactive sudo or prints the command to run. The download goes to `~/tmp`, a run with less than 4 GB free (`GENESIS_BROWSER_MIN_FREE_GB`) is skipped, and a re-run does nothing when everything is in place. A `genesis-browser-stack.service` unit can run it unattended; it refuses to run inside a Claude Code session.
