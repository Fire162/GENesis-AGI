- **Genesis now refuses to type, store or send a payment card number through its general tools.** `browser_fill` refuses a card number as the value, refuses a card field (number, security code, expiry) as the target, and refuses when its click leaves focus in one, including inside a payment iframe. `browser_press_key` allows only navigation keys while focus is in a card field, and `browser_run_js` refuses a script containing a card number. `reference_store` and automatic reference capture never save one, and outbound posts flag one as critical. Detection needs a known card brand prefix and length plus a valid checksum, so ordinary long numbers pass. Card entry is meant for the encrypted card vault tracked in #3172.
